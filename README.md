# SMART Agents

Operational architecture for reliable large language model (LLM) agent systems.

This repository contains the implementation accompanying the paper:

SMART Agents: An Operational Architecture for Reliable LLM Agent Systems.

## Installation

pip install -r requirements.txt

## Usage

Open the notebook:

SMART_Agents_LLM_Reliability.ipynb

and run the cells sequentially.

## API Key

Set your OpenAI API key:

export OPENAI_API_KEY="your_api_key"
